# Shop with Confidence API

FastAPI service for the AI Stylist and virtual try-on workflow.

Public routes are mounted by Vercel at `/api/health`, `/api/recommend`, `/api/tryon`, and `/api/upload`. Run locally with `uvicorn main:app --reload --port 8000`; use the same `/api` prefix when calling it directly.

See the repository [README](../README.md), [API reference](../docs/API.md), and [deployment guide](../docs/DEPLOYMENT.md) for configuration and operational details.
